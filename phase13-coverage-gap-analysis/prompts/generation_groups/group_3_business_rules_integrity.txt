- requirement_id

- title
- priority (must be exactly one of: "High", "Medium", "Low")

- test_data
- steps
- expected_result
- automation_candidate (must be exactly one of: "Yes", "No")

- preconditions must describe the state of the system/account before the test, not restate the title.
- source_traceability should name the source file if one is available in the RAG Context, otherwise use "Source: requirement".
- No comments, no trailing commas.
